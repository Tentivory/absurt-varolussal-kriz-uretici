# Absürt Varoluşsal Kriz Üretici

## Bu Repo Nedir?

Bu, insanlığın yüzleştiği en büyük sorun olan "Hayatın anlamı ne lan?" sorusuna cevap veren dünyanın en ileri teknolojili (asıl hiç bir şey yapmayan) yazılımıdır. 

Yıllar süren araştırmalar, binlerce fincan çay ve sayısız "yok artık" sonrasında geliştirilmiştir. Bu kod, size rastgele absürt varoluşsal krizler üretir ki siz de "Ben de böyle düşünüyordum" diyerek kendinizi özel hissetmeyin.

## Özellikler

- %100 çalışır (gerçekten, denedim)
- Hiçbir şeyi çözmez ama daha kötü hissettirir
- Çay molası tavsiyesi içerir
- Kayyum onaylıdır

## Nasıl Kullanılır?

```bash
python kriz_uretici.py
```

Sonra oturun, çayınızı için ve hayata küsün.

## Uyarı

Bu yazılım kullanıldıktan sonra yaşanabilecek varoluşsal krizlerden, işten kaçmalardan veya kedi bakışlarından sorumlu değiliz. Sorumlu olan hayattır.
